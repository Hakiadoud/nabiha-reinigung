# Nabiha Reinigung – Website

Website der Gebäudereinigung **Nabiha Reinigung** (Minden) in 6 Sprachen.

## Inhalte bearbeiten
Alle Texte, Bilder, Öffnungszeiten und Kontaktdaten werden über **Pages CMS** bearbeitet:
https://app.pagescms.org

Nach dem Speichern baut GitHub die Website automatisch neu (ca. 1–2 Minuten).

## Aufbau
- `content/` – alle Inhalte (JSON), werden im CMS bearbeitet
- `img/` – Bilder
- `template.html` – Design und Aufbau (nur für Entwickler)
- `build.mjs` – erzeugt die fertige Website in `dist/`
- `.pages.yml` – Konfiguration der Bearbeitungsoberfläche
